# ENEVRIDE PLATER COUNT

ENEVRIDE PLATER COUNT is a Minecraft plugin designed to display the number of online players on the server in real-time. It also shows the location of the sleep message when players enter a bed, providing a comprehensive view of server activity. This plugin is perfect for server administrators and players who want to stay informed about the server's current status.

## Install

1. Download the plugin JAR file from the [GitHub repository](https://github.com/EnderDevelopment/ENEVRIDE-PLATER-COUNT).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Once the server is running with the plugin installed, players can use the `/playerinfo` command to see the current number of online players.
2. The plugin will automatically display the number of online players on the server's scoreboard.
3. When a player enters a bed, the plugin will broadcast a message showing the player's name and the location of the bed.
